# Простая консольная база данных

Учебный проект на Python: консольная база данных с управлением таблицами и сохранением их структуры в JSON.

## Требования

- Python 3.14+
- Poetry 2.x
- Make

## Установка

```bash
make install
```

## Запуск

```bash
make project
```

## Проверка кода

```bash
make lint
```

## Сборка пакета

```bash
make build
```

## Управление таблицами

Второй этап: создание, удаление и просмотр структуры таблиц.
Метаданные сохраняются в `db_meta.json` в текущем рабочем каталоге.
Файл создаётся после первого успешного изменения; перезапуск не теряет таблицы.

### Запуск

```bash
make install
make run
```

Также доступны `poetry run database` и прежняя команда `make project`.

### Команды

- `create_table <имя> <столбец:тип> ...` — создать таблицу.
- `drop_table <имя>` — удалить таблицу.
- `list_tables` — вывести имена всех таблиц.
- `help` — показать справку.
- `exit` — завершить работу.

Поддерживаемые типы: `int`, `str`, `bool`. Столбец `ID:int` автоматически
становится первым. Если пользователь указал его сам, второй ID не создаётся.
Повторяющиеся имена столбцов, неправильный формат и неизвестные типы отклоняются.
На этом этапе сохраняется структура таблиц; сами записи появятся на этапе CRUD.

### Пример

```text
create_table users name:str age:int is_active:bool
list_tables
exit
```

После повторного запуска:

```text
list_tables
drop_table users
list_tables
exit
```

Создание существующей и удаление отсутствующей таблицы выводят ошибку.
Повреждённый файл метаданных не заменяется пустой базой: программа сообщает
об ошибке чтения и завершает работу.
