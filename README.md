# Простая консольная база данных

Учебный проект на Python. Пока реализован ввод команд `help` и `exit`.

## Требования

- Python 3.14+
- Poetry 2.x
- Make

## Установка

```bash
make install
```

## Запуск

```bash
make project
```

## Проверка кода

```bash
make lint
```

## Сборка пакета

```bash
make build
```
